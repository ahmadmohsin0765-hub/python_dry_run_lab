🚀 How it Works

The Python Dry-Run Lab runs your Python code entirely in the browser using Pyodide (WebAssembly). Before running, it analyzes the syntax and compiles it with an in-worker sys.settrace recording hook. Every step captures the full stack, local and global variables, memory object graphs, and output stream into a time-travel sequence.

☁️ Deploy to Vercel

This app is 100% single-file, requiring zero build steps or backend servers. Simply push this repository to GitHub and import it on Vercel as a Static Site.
